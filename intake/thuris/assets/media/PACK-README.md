# THURIS Web Image Pack v1

Production-oriented website asset pack generated 2026-10-21.

## Folder structure
- reference/ — canonical product-design reference for visual QA.
- masters/ — full PNG generation masters.
- web/ — compressed WebP derivatives with matching filenames.
- agent-image-map.json — machine-readable placement map.
- site-placement.md — human-readable placement instructions.

## Product design authority
Heavy 10 ml violet-black rectangular glass, thick optical base, short neck, solid brushed-champagne-metal screw cap, concealed internal orifice reducer. No pipette, rubber bulb, cork/stone cap, or spray.

## Important
The earlier moodboards/collages are intentionally not in this production pack: some used superseded closure architecture or were conceptual boards rather than deployable page assets.
